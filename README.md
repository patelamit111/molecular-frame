# Molecular Frame

The public website for Molecular Frame, an AI-native pharma film studio.

## Local development

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and provide a Resend API key to enable direct pilot-request delivery. Without it, the form returns a precomposed email fallback.

## Required Aspirin media

The site expects these optimized public assets:

- `public/media/aspirin/aspirin-flagship-web.mp4`
- `public/media/aspirin/aspirin-hero-loop.mp4`
- `public/media/aspirin/aspirin-poster.webp`
- `public/media/aspirin/aspirin-captions.vtt`
- `public/media/aspirin/aspirin-cox1-detail.webp` (optional)

Concept films are presented as independent portfolio studies. They must not be represented as client work.
